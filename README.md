# Hamed Abdollahzade Portfolio

سلام! 👋  
این پروژه پورتفولیوی من است که با **React**, **Vite**, **Tailwind CSS** و **Ant Design** ساخته شده است. هدف این پروژه نمایش مهارت‌ها، پروژه‌ها و تجربیات حرفه‌ای من به شکل یک رابط کاربری مدرن و ریسپانسیو است.

---

## ⚡ ویژگی‌ها

- طراحی **ریسپانسیو** برای نمایش در موبایل و دسکتاپ  
- استفاده از **Tailwind CSS** برای استایل‌دهی سریع و قابل شخصی‌سازی  
- استفاده از **Ant Design** برای کامپوننت‌های حرفه‌ای و آماده  
- **React Router** برای ناوبری بین صفحات  
- نمایش **نمونه کارها، مهارت‌ها و رزومه** به صورت منظم  
- تجربه کاربری **Smooth** با انیمیشن‌های ساده و جذاب  
- آماده برای **استقرار روی GitHub Pages** یا هر سرویس میزبانی استاتیک  

---

## 🛠️ تکنولوژی‌ها

- **React** – کتابخانه محبوب برای رابط کاربری  
- **Vite** – ابزار سریع برای ساخت و توسعه پروژه  
- **Tailwind CSS** – فریم‌ورک CSS کاربردی  
- **Ant Design** – مجموعه کامپوننت‌های UI  
- **React Router** – مدیریت مسیرهای اپلیکیشن
