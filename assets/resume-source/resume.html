درباره من

من یک توسعه‌دهنده‌ی فرانت‌اند با بیش از چهار سال تجربه‌ی حرفه‌ای در حوزه‌ی وب هستم. در این مدت با استفاده از تکنولوژی‌های مدرن مانند HTML، CSS، JavaScript و TypeScript پروژه‌های متنوعی را توسعه داده‌ام. تمرکز اصلی من روی کتابخانه‌ها و فریم‌ورک‌های محبوبی مثل React، Redux Toolkit و Vue 3 بوده و در طراحی رابط کاربری از Ant Design، Tailwind CSS، MUI، Bootstrap و Sass بهره گرفته‌ام.

تجربه‌ی قابل توجهی در ساخت رابط‌های کاربری پویا با استفاده از GSAP و Framer Motion دارم و در زمینه‌ی طراحی و تجربه کاربری نیز با Figma به خوبی کار می‌کنم. در پروژه‌هایم از React Router، Zustand برای مدیریت وضعیت و از Axios برای ارتباط با APIها استفاده کرده‌ام. همچنین در حوزه‌ی داده و تحلیل بصری، با ابزارهایی مثل Ant Design Charts، Ant Design Plots و ECharts آشنا هستم.

در بخش تست و کیفیت کد، با Vitest، Testing Library، ESLint و Prettier کار کرده‌ام و همیشه سعی می‌کنم اصول clean code و متدولوژی چابک (Agile) را رعایت کنم. از ابزارهای Vite، CRA، Git و GitHub نیز برای توسعه و مدیریت پروژه‌ها استفاده می‌کنم.

همچنین با کتابخانه‌ها و ابزارهای تخصصی‌تر مانند نشان مپس (React و OpenLayers)، تولید فایل‌ها (React‑PDF، html2canvas، XLSX)، ساخت بارکد و QR، ابزارهای زمان (Dayjs، Moment، Jalaliday)، کتابخانه‌های Utility مثل Lodash و ابزارهای Drag & Drop از جمله DnD‑Kit و SortableJS تجربه عملی دارم. در پروژه‌های Real‑Time نیز از Pusher.js و Laravel Echo استفاده کرده‌ام.
